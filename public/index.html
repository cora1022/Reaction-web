    반응속도 테스트 사용 방법

    1. 측정 화면을 눌러 테스트를 시작합니다.
    2. 빨간색 대기 화면에서는 누르지 않고 초록색 신호를 기다립니다.
    3. 초록색으로 바뀌면 가능한 한 빠르게 화면을 누릅니다.
    4. 5회 측정을 마치고 평균·최고 기록과 기준 분포에서 내 위치를 확인합니다.

    같은 기기를 사용하세요

    마우스, 터치 화면과 키보드는 입력 지연이 다르므로 기록을 비교할 때 같은 방식을 사용하세요.

    신호를 예상하지 마세요

    초록색이 나타나는 시간은 매번 달라집니다. 화면을 미리 누르면 해당 시도는 기록되지 않습니다.

    여러 번 비교하세요

    한 번의 결과보다 5회 평균이 현재 집중 상태와 반응을 비교하는 데 더 유용합니다.

    반응속도 결과를 해석하는 방법

    이 테스트는 초록색 신호를 화면에 표시한 시점과 사용자가 화면을 누른 시점의 차이를 브라우저의 고해상도 시계로 계산합니다. 인터넷 통신 시간은 측정에 포함되지 않지만 디스플레이 주사율, 마우스·터치 입력 지연과 브라우저 상태는 결과에 영향을 줄 수 있습니다.

    회차별 선 그래프는 5번의 기록이 얼마나 일정했는지 보여줍니다. 한 번만 유난히 느린 기록이 있다면 순간적인 집중 저하나 입력 지연일 수 있으므로, 최고 기록 하나보다 5회 평균과 변화 폭을 함께 보는 편이 좋습니다.

    최종 분포 그래프는 평균 250ms, 표준편차 50ms인 단순 비교 모델에 내 평균을 표시한 참고 자료입니다. 실제 인구 통계나 의학적 평가가 아니므로 절대적인 능력 순위로 해석하지 말고, 같은 기기와 입력 방식에서 자신의 기록 변화를 비교하는 용도로 사용해 주세요.

    자주 묻는 질문

    반응속도는 어떻게 측정하나요?

    초록색 신호가 화면에 표시된 시점부터 화면을 누른 시점까지 걸린 시간을 브라우저의 고해상도 시계로 계산합니다.

    평균 반응속도는 몇 ms인가요?

    기기 성능과 입력 장치, 집중 상태에 따라 결과가 달라집니다. 절대적인 등급보다 같은 환경에서 기록이 어떻게 변하는지 비교하는 용도로 사용해 주세요.

    너무 빨리 누르면 어떻게 되나요?

    빨간색 대기 화면에서 누르면 부정 출발로 처리합니다. 진행 중인 기록은 모두 초기화되며 화면을 다시 눌러 1회차부터 시작할 수 있습니다.

    측정 기록이 서버에 저장되나요?

    최근 평균과 최고 기록은 이 기기의 브라우저 저장 공간에만 보관되며 서버로 전송하지 않습니다.

    정규분포 결과는 절대적인 순위인가요?

    아닙니다. 평균 250ms와 표준편차 50ms를 사용한 단순 비교 모델의 참고 결과입니다. 기기 성능과 입력 장치, 화면 주사율에 따라 기록이 달라질 수 있습니다.
